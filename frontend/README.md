# ResearchGPT Frontend

The frontend will provide the user interface for:

- PDF upload;
- processing status;
- paper classification;
- technical entities;
- summary;
- semantic search;
- question answering;
- retrieved source context.

## Planned Screens

```text
Upload
  ↓
Paper Overview
  ├── Classification
  ├── Entities
  ├── Summary
  └── Search / Ask
        ↓
Question Answer
        ↓
Sources
```

The frontend framework and exact implementation will be selected and documented during the frontend task.
