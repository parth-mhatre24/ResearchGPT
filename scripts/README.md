# ResearchGPT Scripts

This directory contains reproducible command-line utilities.

Planned scripts include:

```text
download_datasets.py
train_classification.py
train_ner.py
train_summarization.py
evaluate_models.py
```

Scripts must:

- expose clear command-line arguments;
- avoid hard-coded user-specific paths;
- record configuration;
- return meaningful exit codes;
- be tested where practical.
