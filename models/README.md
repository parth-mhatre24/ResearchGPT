# ResearchGPT Models

This directory is reserved for model configuration and approved model artifacts.

## Planned Areas

```text
models/
├── classification/
├── ner/
├── summarization/
└── qa/
```

Large model artifacts should not be committed to Git unless an explicit storage strategy has been approved.

Each model artifact must have associated metadata describing its:

- task;
- checkpoint;
- tokenizer;
- dataset;
- version;
- evaluation;
- configuration.
